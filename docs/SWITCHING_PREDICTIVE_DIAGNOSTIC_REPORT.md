## Class Imbalance And LOSO Shift

Generated files:

```text
outputs/switching_predictive/user_label_distribution.csv
outputs/switching_predictive/user_prediction_distribution.csv
outputs/switching_predictive/user_confusion_matrices.json
```

The user-level label distribution is highly uneven:

- Several users are single-class only:
  - `Graja`, `Makki`, `ignorant`: only `Bored`
  - `amrdroid`, `ghoss`, `ladabos`, `mohanned`: only `Neutral`
- `dem` has 161 samples and is dominated by `Distracted`.
- `hffz` contains many `Overloaded` samples.
- `layss` is more mixed than most users.

This creates a hard LOSO shift: when a user is held out, the test user's label
distribution can be absent or underrepresented in the training users.

## Factor Regression

Factor regression is stronger than state classification:

```text
factor_MAE  = 0.200
factor_RMSE = 0.269
```

This suggests the continuous NASA-TLX factor targets may contain a learnable
signal, while the derived 5-class state labels are noisy, imbalanced, or too
coarse for LOSO generalization.

## Implemented Training Options

The training code now supports:

```text
--class-weights none|balanced
--state-loss ce|focal
--state-mode 5class|3class
--task joint|regression_only|classification_only
```

Balanced class weights are computed from the training fold only:

```text
weight_c = N_train / (num_classes * count_c)
```

Focal loss is implemented as:

```text
focal_loss = -alpha_t * (1 - p_t)^gamma * log(p_t)
```

Default:

```text
gamma = 2.0
alpha = class weights if enabled
```

Smoke-tested modes:

- `5class + balanced CE + joint`
- `3class + balanced CE + joint`
- `regression_only`

Full LOSO comparison for class weights, focal loss, 3-class mapping, and
regression-only training is implemented but still needs full experiment runs.

## Recommendation

Do not trust the current 5-class switching state classifier yet.

Recommended next steps:

1. Run the 3-class balanced CE experiment first.
2. Run regression-only training and compare factor MAE/RMSE.
3. Compare every experiment against:
   - LOSO-safe `majority_class`
   - `stratified_random`
   - `simple_mlp`
   - global `Neutral` reference only as interpretability baseline
4. Inspect users with single-class labels before blaming the model.
5. If 3-class still fails, revisit the target design or collect more balanced
   per-user windows before adding model complexity.
